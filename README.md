# KIBERone ИгроВАН — Пробный урок 2.0

Веб-приложение для усиления пробного урока KIBERone. Цель — поднять конверсию с 45% и снизить отток за счёт WOW-эффекта во время урока и сразу после него.

## Готовые спринты

### Спринт 1: Мини-лендинг с игрой + QR ✅
Наставник загружает Scratch-проект ребёнка → уникальная ссылка и QR. Родитель сканирует → играет в созданную ребёнком игру прямо в браузере, делится в WhatsApp/Telegram.

### Спринт 2: Сессия пробного урока + дашборд родителя ✅
Наставник создаёт сессию на месте → получает QR для родителя. По ходу урока тыкает 7 чекпойнтов («герой ожил», «игра запустилась», «защита проекта»). Родитель в реальном времени видит прогресс ребёнка на своём телефоне и параллельно проходит 5-вопросный тест («какое из 4 направлений подойдёт»). Через 1 час после финиша — автоотправка видео-нарезки в WhatsApp через Wazzup24.

### Спринт 3: Персональный отчёт через 24 часа ✅
Через сутки worker отправляет родителю ссылку на красивую страницу `/parent/<token>/report` с персональным разбором урока: что увидели наставники, в чём сильные стороны ребёнка, какое направление KIBERone подойдёт. Отчёт генерирует Claude Haiku 4.5 с prompt caching (системный промпт кэшируется → 0.1x стоимость со второго отчёта). Без API-ключа модуль работает в fallback: шаблонный отчёт по структуре чекпойнтов.

### Спринт 4: Паспорт разработчика KIBERone ✅
В админке сессии — кнопка «Выдать паспорт» (опционально загружается фото 3×4). Серийник формируется автоматически: `KBR-{год}-{код филиала}-{NNNN}` (счётчик персональный для каждого филиала). Грейд из возраста: **Padawan / Cadet / Engineer / Architect**. Направление — из теста родителя.

Печатается прямо из браузера (Ctrl+P → A6 portrait). Лицевая сторона: фото, имя, грейд, трек, ID, дата, QR на профиль. Обратная: 8 ачивок-штампов (1 предзаполнена «Первая игра создана», остальные ставит наставник на занятиях). Стилизовано как настоящие корпоративные badges — премиальный вид без типографии.

**WOW-эффект:**
- Игра ребёнка запускается **прямо в браузере телефона** родителя (TurboWarp Scaffolding) — никаких установок
- Имя ребёнка крупным шрифтом, персональный сертификат
- Родитель **видит мозг ребёнка в действии** — каждый этап урока в реальном времени
- Через час получает короткое видео и ссылку на игру
- Кнопка «Поделиться» → бабушка/папа получают ссылку → виральный канал привлечения

## Как использовать на пробном уроке

### До урока
- Запусти `start.bat` на компьютере наставника
- Если нужно показать страницу с телефона родителя — компьютер и телефон должны быть в одной Wi-Fi сети. Тогда вместо `localhost:5000` родитель открывает `http://<IP компьютера>:5000`.
- Узнать IP: `ipconfig` → строка `IPv4-адрес`. Обнови `BASE_URL` в `.env` под этот IP, перезапусти сервер.

### В начале урока — создать сессию
1. Открой http://localhost:5000/admin → «🚀 Начать пробный урок»
2. Заполни: имя ребёнка, возраст, имя родителя, телефон, имя наставника
3. На экране появится **QR-код для родителя** — дай отсканировать
4. Родитель увидит страницу с именем ребёнка и пустыми чекпойнтами

### По ходу урока — тыкать чекпойнты
В админке сессии 7 этапов: «Прибыл», «Знакомство», «Первые блоки», «Герой ожил», «Появились вызовы», «Игра работает», «Защита проекта». Тыкай по мере выполнения — у родителя обновляется живой прогресс через 4 секунды.

### Между чекпойнтами — родитель проходит тест
На странице родителя кнопка «Пройти тест». 5 вопросов о ребёнке → результат: одно из 4 направлений (Game / AI / Web / Robotics).

### Перед финишем — видео-нарезка
Сними короткое видео (30-60 сек) с момента запуска игры / защиты. Загрузи в админке сессии (раздел «📹 Видео-нарезка»).

### Финиш урока
1. Нажми «🏁 Завершить урок»
2. Загрузи .sb3 ребёнка — кнопка «Загрузить готовую игру» появится автоматически
3. На странице родителя сразу появится секция «🎉 Игра готова» с кнопкой просмотра

### Через 1 час — автоотправка видео + ссылок
Worker (`worker.bat`) проверяет завершённые сессии и через час отправляет родителю шаблонное сообщение в WhatsApp через Wazzup24: «Здравствуйте, [имя]! Вот игра ребёнка и видео с урока…». Если Wazzup24 не настроен — пишет в лог (dry-run).

### Через 24 часа — персональный отчёт
Тот же worker через сутки генерирует через Claude API персональный отчёт (заголовок, 3 наблюдения, ключевые выводы, CTA) и отправляет родителю ссылку. Открывается красивая страница, родитель может «Сохранить как PDF» в браузере. Для генерации нужен `ANTHROPIC_API_KEY` в `.env`, иначе — fallback на шаблон.

**Срочно?** В админке сессии есть кнопка «Сгенерировать отчёт сейчас» — для горячих клиентов или для теста.

**Запуск worker:** двойной клик `worker.bat`. Можно настроить Windows Task Scheduler на автозапуск при старте.

## Стек

| Компонент | Чем |
|---|---|
| Бэкенд | Python 3.10+ / Flask 3 |
| Прод-сервер | Waitress (WSGI для Windows) |
| Scratch-плеер | [@turbowarp/scaffolding](https://github.com/TurboWarp/scaffolding) (через CDN) |
| QR-коды | python-qrcode |
| Стили | чистый CSS, тёмная тема |
| Сообщения родителю | Wazzup24 API (WhatsApp Business) |
| Polling родителя | fetch /parent/<token>/status.json раз в 4 секунды |
| AI-отчёт | Anthropic Claude (Haiku 4.5) + prompt caching + tool use |

## Конфигурация (`.env`)

| Переменная | Что |
|---|---|
| `BASE_URL` | Публичный URL сервера. Для локалки — `http://localhost:5000`. Для прода — `https://trial.kiberone.ru`. Используется в QR-кодах и ссылках шеринга. |
| `ADMIN_PASSWORD` | Пароль для входа в /admin |
| `DEFAULT_FILIAL` | Подставляется в форму по умолчанию |
| `SECRET_KEY` | Секрет для сессий Flask (рандомь в проде) |

## Деплой в прод (для масштабирования)

Когда пилот в Челнах подтвердит ВАУ-эффект — выкатываем на домен:

1. Купить домен/поддомен (например, `trial.kiberone.ru`)
2. Поднять Python-хостинг (Yandex Cloud / Timeweb / Beget)
3. Подменить `BASE_URL` на публичный
4. Прикрутить S3 для `.sb3` файлов (если >1000 пробных накопится)
5. SSL обязателен — без HTTPS WhatsApp/Telegram кнопки шеринга работают через раз

## Деплой на trial.kiberone.ru

Production-комплект готов в [deploy/](deploy/):

- `Dockerfile` — образ приложения (Python 3.12 slim + waitress)
- `deploy/docker-compose.prod.yml` — web + worker как отдельные контейнеры, тома для данных
- `deploy/nginx-trial-kiberone.conf` — nginx-сайт с проксированием на 127.0.0.1:8000
- `deploy/.env.prod.example` — продакшен-шаблон (сильный пароль, SSL URL)
- `deploy/deploy.sh` — скрипт обновления на сервере (`git pull` → `docker compose up`)
- **`deploy/DEPLOY.md` — пошаговая инструкция на 30-60 минут**

Краткое содержание DEPLOY.md (10 шагов):

1. DNS — A-запись `trial.kiberone.ru` → IP сервера
2. SSH на VPS (Ubuntu/Debian)
3. Установить Docker
4. Установить nginx + certbot
5. Залить код в `/opt/igrovan-trial` (rsync или git)
6. Скопировать и заполнить `.env`
7. `docker compose up -d --build`
8. Подключить nginx-сайт
9. SSL через certbot
10. Финальная проверка + тестовая сессия

## Что НЕ делает (намеренно)

- **Не интегрирован с CRM** (s20.online / AlphaCRM) — пока ручной ввод данных в админке. Следующий шаг — забирать сессию по `parent_phone` из CRM автоматически.
- **Не отправляет файлы напрямую** через Wazzup24 — отправляем ссылки на свою страницу. После деплоя на trial.kiberone.ru это работает.
